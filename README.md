# KRAS in Colorectal Cancer: A Multi-Project Bioinformatics Investigation

A comprehensive research program exploring KRAS mutations in colorectal cancer from multiple angles — from gene expression analysis to AI-driven variant prediction and drug repurposing.

## 📁 Projects

### 1. Original Analysis (GSE39582)
Identified 38 DEGs and 5 hub genes (CLCA1, SPINK4, MUC2, REG4, TFF1) associated with KRAS mutations in colorectal cancer.
→ [View Project](./01_Original_Analysis/)

### 2. AI Variant Effect Prediction (ESM-2)
Used ESM-2 protein language model to predict the impact of KRAS mutations.
→ [View Project](./02_AI_Variant_Prediction/)

### 3. Multi-Omics Validation (TCGA)
Validated hub gene findings in an independent TCGA cohort using cBioPortal API.
→ [View Project](./03_MultiOmics_TCGA/)

### 4. Network-Based Drug Repurposing (DGIdb)
Built a drug-gene interaction network to identify potential repurposing candidates.
→ [View Project](./04_Drug_Repurposing/)

## 🛠️ Tools & Technologies
Python, Biopython, ESM-2, NetworkX, GEOparse, gseapy, cBioPortal API, DGIdb API, Google Colab

## 📊 Key Findings
- 38 DEGs and 5 hub genes identified in KRAS-mutant CRC
- Hub genes validated in independent TCGA cohort
- MUC2 identified as potential target for Mirametinib
- CLCA1, SPINK4, REG4, TFF1 represent "drug gaps"
